# Stardew Valley Web - Enciclopedia Inmersiva

## Descripción del Proyecto

Stardew Valley Web es una plataforma web interactiva e inmersiva concebida al estilo de una enciclopedia "wiki" sobre el afamado videojuego Stardew Valley. El proyecto combina un diseño moderno y adaptativo con una arquitectura dinámica orientada a la consulta de información en tiempo real.

El propósito de esta aplicación es ofrecer una experiencia fluida e intuitiva para consultar información detallada sobre personajes, cultivos, mecánicas, estaciones y objetos del juego, integrando peticiones asíncronas para una navegación interactiva sin necesidad de recargas completas de página.

## Tecnologías Utilizadas

HTML5 & CSS3: Estructuración semántica y diseño personalizado.

Bootstrap: Framework CSS para maquetación ágil y diseño responsive.

PHP: Procesamiento de lógica de negocio y servidor.

SQL: Gestión y estructuración de la base de datos relacional para el contenido de la enciclopedia.

AJAX: Peticiones asíncronas para actualización e intercambio dinámico de datos sin recargar la página.

HTTP: Manejo del protocolo de comunicación e intercambio de datos cliente-servidor.

## Requisitos del Sistema

Para ejecutar el proyecto de manera local se requiere:

Un servidor web local con soporte para PHP y MySQL/MariaDB (ej. XAMPP, WAMP, LAMP o Laragon).

Navegador web actualizado (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).

Gestor de bases de datos (ej. phpMyAdmin, MySQL Workbench o DBeaver).
